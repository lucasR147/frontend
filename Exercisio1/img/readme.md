As pastas criadas separadas css, html, java e img, refere-se a cada etapa da estrutura e criação do código, separando as funções de cada etapa, afim de facilitar na criação e na correção de alguma falha futura. 
Afim de mitigar o gargalo e a complexidade de correção caso aja a necessidade de adicionar ou corrigir algum erro futuro.
