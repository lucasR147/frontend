# frontend


FrontEnd = É a parte de um sistema web que aparece para o usuário no navegador. 
Ele envolve a estrutura do conteúdo, o visual da página e as interações que acontecem do lado do cliente. 
Quando uma pessoa acessa uma página, clicar em botões, ler textos, navegar por menus ou visualizar imagens, ela está interagindo com o Frontend.

CSS = Controla a aparência visual, como cores, tamanhos, espaçamentos e posicionamento. 

HTML = Organiza o conteúdo e define elementos como títulos, parágrafos, listas, links e imagens. 

JavaScript = Adiciona comportamentos e interatividade, como validar campos, abrir menus e reagir a cliques.


W3R = O W3C é uma organização internacional relacionada aos padrões da Web. 
Seu papel é ajudar a manter tecnologias interoperáveis, acessíveis e consistentes entre navegadores, sistemas e dispositivos. 
Para um técnico em informática, conhecer padrões ajuda a criar páginas que funcionam melhor em ambientes diferentes.


Cliente x Servidor = O cliente é o dispositivo ou programa usado pelo usuário, como um navegador em um computador ou celular. 
O servidor é o computador remoto que armazena, processa e entrega recursos como páginas HTML, imagens, arquivos CSS, scripts JavaScript e dados. 
Quando o cliente pede uma página, o servidor responde com os arquivos necessários para que o navegador monte a interface.
